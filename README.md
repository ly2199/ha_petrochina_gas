# 中石油燃气统计 (PetroChina Gas)

Home Assistant 自定义集成,用于查询**中石油昆仑燃气**(云南昆明分公司等)燃气账户的余额、表读数、阶梯气价、用气量与缴费记录等数据。

> ⚠️ **非官方集成**。数据通过中国石油燃气云平台(`bol.grs.petrochina.com.cn`,与微信公众号/小程序同源)的接口获取,接口可能随时调整;填写的登录凭证仅保存在本地 HA 配置条目中,不会上传到任何第三方。

## 功能特性

- **输入 8 位燃气户号即可添加**,走免认证公开接口获取基础余额信息
- **可选填手机号 + 密码**:自动登录后获取详细数据(阶梯气价、月/年/近31天用量与费用、缴费记录、用气地址等)
- **支持多户号**,每个户号一个配置条目,互不干扰
- 传感器覆盖余额、欠费、表读数、最近通讯、各周期用量/费用、当前阶梯档位与单价等 20+ 项
- 可配置数据刷新间隔(默认 1 小时,最低 60 秒);登录 Token 过期时自动重新获取

## 安装

### 方式一:HACS(推荐)

1. HACS → 右上角 `⋯` → **自定义存储库 (Custom repositories)**
2. 存储库地址填 `https://github.com/ly2199/petrochina_gas`,类别选 **集成 (Integration)** → 添加
3. 在 HACS 中搜索 **中石油燃气统计 (PetroChina Gas)** → 下载 → **重启 Home Assistant**

### 方式二:手动安装

将本仓库 `custom_components/petrochina_gas/` 整个文件夹复制到 Home Assistant 配置目录的 `custom_components/petrochina_gas/` 下(如已存在请先删除旧文件夹),然后重启 Home Assistant。

## 配置

设置 → 设备与服务 → 添加集成 → 搜索 **昆仑燃气**:

| 配置项 | 说明 |
|---|---|
| 燃气户号 (user_code) | 8 位数字,必填 |
| 地区代码 (cid) | 必填,默认 `2` = 昆明;其他地区请咨询当地燃气公司 |
| 手机号 (mobile) | 选填,填写后可自动登录获取详细数据 |
| 登录密码 (password) | 选填,配合手机号使用 |

- **填写手机号/密码**:自动登录,可获取阶梯气价、缴费记录、各周期用量等完整数据
- **不填写**:仅使用免认证公开接口获取基础余额信息

添加完成后,可进入集成 **选项 (Options)** 修改:

- **更新间隔设置**:数据轮询间隔(秒,不得低于 60)
- **认证信息设置**:更新手机号/登录密码(留空保持不变)

## 传感器

每个户号会创建以下传感器(显示名以 HA 界面为准):

| 类型 | 说明 |
|---|---|
| 表端余额 / 待上表金额 | 余额与欠费 |
| 户号 / 用户名 / 用气地址 / 所属燃气公司 | 账户与客户信息 |
| 最近表读数 / 表具最后通信时间 | 远传表信息 |
| 本月用气量/费用、上月用气量/费用、近31天累计用量/费用 | 用气统计 |
| 最近一日用气量 / 最近用气日期 / 最近一日用气费用 | 日用量 |
| 年度用气量 / 年度用气费用 | 年用量 |
| 当前阶梯档位 / 当前阶梯单价 / 当前阶梯剩余用量 | 阶梯气价 |
| 最近缴费金额 / 最近缴费时间 | 缴费记录 |
